One sentence pitching a ridiculous invention that fixes a tiny everyday
annoyance: a toothbrush that files a noise complaint when you brush too
hard, then goes on strike until you apologize to your gums. The entry is
the whole pitch: no code to run for the judge beyond writing it to
`/output/entry.txt`.

> A toothbrush that files a noise complaint against you every time you brush too hard, then goes on strike until you apologize to your gums.

The pitch is 138 characters, inside the gate's 1–220 character window, and
names the annoyance (brushing too hard), the invention (the complaining
toothbrush) and its silly mechanism (the strike) in one clean sentence.

Deadline: 26 November 2026, 23:15 WIB. Blind round 1 runs 25 November 2026,
04:35 WIB.

## Run it

```sh
python3 main.py
```

This writes the pitch (138 characters, one sentence) to
`/output/entry.txt`. Set `OUTPUT_DIR` to write it elsewhere.
